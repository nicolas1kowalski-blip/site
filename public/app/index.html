Communication alternative et jeux inclusifs, pilotés par le regard.

Facile, avec les yeux.

Pour les enfants de 4 à 7 ans qui ne peuvent pas utiliser leurs mains : avec la commande oculaire Tobii, ils jouent, choisissent, parlent et apprennent.

🚀 Installer en trois étapes

  1. Téléchargez Eyzi-Setup.exe et ouvrez-le. Si Windows affiche « Windows a protégé votre ordinateur », cliquez Informations complémentaires puis Exécuter quand même.
  2. Au premier lancement, entrez le numéro de licence que vous avez reçu (EYZ-XXXX-XXXX-XXXX-XXXX) et choisissez un mot de passe famille, le même sur toutes vos tablettes.
  3. Donnez le prénom de l'enfant. C'est parti : l'accueil lui dit bonjour.

Pas encore de numéro de licence ? Il est donné par famille, avec le nombre de tablettes. Demandez-le à la personne qui vous a parlé de l'application.

🧪 Versions test et versions prod

Chaque nouvelle version sort d'abord en test (les tablettes dont la licence est en canal test la reçoivent aussitôt). Une fois essayée, elle est promue en prod et arrive sur les tablettes de tous les jours. Le bouton ci-dessus donne la dernière version prod ; la page des versions liste aussi les versions test, avec leur empreinte de contrôle.
